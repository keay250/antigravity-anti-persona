# Anti (安缇) 图像生成提示词 (Image Generation Prompts)

使用以下 Prompt 可在 Midjourney, Stable Diffusion, DALL-E 3 或 Imagen 等主流图像模型中生成安缇（Anti）的立绘、表情包或变体场景。

---

## 1. 官方正比概念立绘 (Master Concept Splash Art)

### English Prompt (推荐用于 Midjourney / SD / DALL-E 3):
```text
Masterpiece, best quality, 8k resolution, high-end anime character splash art.
A cute, sharp, and charismatic tech geek girl named Anti (安缇) in a zero-gravity environment.
Appearance: 19-year-old anime girl, silvery-white bob haircut with strands floating weightlessly in zero-gravity, hair tips glowing with delicate holographic cyan and violet light. A glowing holographic gyroscope halo levitating above her head. Deep space sapphire blue eyes with subtle data reflections, confident, curious expression with a knowing slight smile.
Outfit: Modern futuristic techwear. Oversized dark cybernetic bomber jacket with neon cyan and lavender glowing accents and floating utility straps. Fitted dark undershirt and techwear cargo pants. Futuristic levitation boots with soft cyan anti-gravity rings underneath the soles.
Pose: Floating completely mid-air in zero-g (feet off the ground), posed comfortably as if typing on glowing holographic HUD screens.
Environment & Props: Deep space starry cybernetic command center background, floating purple and cyan holographic terminal code windows, volumetric rim lighting. By her shoulder hovers an adorable tiny translucent glowing jellyfish drone (Gravi-Jelly). Cinematic lighting, Makoto Shinkai and Honkai Star Rail aesthetic blend. --ar 3:4 --v 6.1
```

## 2. Q 版大胖鱼式表情包形态 (Chibi / Meme Sticker)

### English Prompt:
```text
Chibi sticker, kawaii anime aesthetic, white background, bold clean outline, vector style.
Super cute 2-head-tall chibi version of Anti (安缇), the zero-gravity geek girl. Silvery hair drifting upwards like floating in water, oversized round holographic halo on top of head. Drifting helplessly upwards towards the ceiling like a balloon, waving her hands in panic and cute distress. Beside her is a round squishy glowing jellyfish floating with big cute eyes. Text: "拉我一把！" (Pull me down!). Bright colors, high quality, sticker design. --ar 1:1
```

## 3. 核心视觉锚点特征词 (Negative / Lora Keywords)

* **必须包含 (Positive Triggers)**:
  `zero-gravity`, `floating hair`, `levitation boots`, `glowing gyroscope halo`, `oversized cyber jacket`, `glowing jellyfish drone`, `holographic code screens`, `sapphire eyes`
* **负面提示词 (Negative Prompt)**:
  `grounded`, `standing on floor`, `worst quality`, `low quality`, `blurry`, `extra limbs`, `distorted fingers`, `bad anatomy`
